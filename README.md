# web-team-operations

Web team 團隊運作與文件整理。

## Folder Structure

- `team-roles/`: Web team 角色規劃與簡報頁面。
- `mybank-backlog-tasks/`: MyBank backlog 與 task 相關紀錄。

## Naming Rules

- 資料夾與一般檔案使用小寫英文。
- 多個單字使用 hyphen `-` 分隔。
- 避免空格、中文、底線與暫時狀態字，例如 `final`、`new`、`整合版`。
- 慣例檔名保留原樣，例如 `README.md`、`.gitattributes`、`index.html`。
